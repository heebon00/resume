→ 표절보다 **허위 경력** 문제다. 취업용 포트폴리오에서 가장 치명적인 항목.

## 🟠 중간 — 출처를 밝히면 해결된다

### M-1. 피그마 시안 자체가 상용 워드프레스 테마에서 온 것 — **확인됨**

피그마 파일 노드 이름에 워드프레스 클래스명이 그대로 남아 있다.

```
div.wpb_wrapper   div.vc_row   div.wpb_column     ← WPBakery Page Builder (구 Visual Composer)
div.ld-fancy-heading   h6.ld-fh-element   div.ld-container   ← LiquidThemes
div#vc_accordion_62ff67320b7cd                      ← WPBakery 자동생성 고유 ID
```

- `ld-fancy-heading` 는 **LiquidThemes 공식 문서에 "Liquid Fancy Heading" 요소**로 등재돼 있다
  (Ave · HUB 테마). Ave 는 ThemeForest 판매 중인 유료 테마다
- `vc_accordion_62ff67320b7cd` 같은 **해시 ID 는 손으로 그린 시안에서는 나올 수 없다.**
  돌아가는 워드프레스 사이트를 피그마로 가져왔을 때만 남는다
- 코드 주석에도 이미 적혀 있다 — `src/content/portfolio.js:7`
  *"피그마 모바일 아트보드(20:1794)는 **테마 원본 영문 페이지**라…"*

**어떤 테마의 어느 데모인지는 특정하지 못했다 (확인 안 됨).** LiquidThemes 계열이라는 것까지가 확인된 범위다.

→ **레이아웃·섹션 구성을 "본인 디자인"이라고 말하면 위험하다.**
   "기존 테마 레이아웃을 참고해 React 로 재구현" 이라고 하면 오히려 강점이 된다
   (구현력을 보여주는 작업이므로).

   덤으로 "출처를 정확히 관리하는 사람"이라는 인상을 준다.
