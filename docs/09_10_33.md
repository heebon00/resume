# 풀(pull) 시도 중 충돌 발견 — 조치 승인 요청

작성 시각: 2026-09-09 10:33 / 브랜치: main / 원격: origin (github.com/heebon00/resume)

## 무슨 일이 있었나
`git fetch`로 원격 상태만 확인했다. **아직 merge/pull은 실행하지 않았다.**
확인 결과 지금 상태로 `git pull` 하면 다음 오류로 실패한다(추정 아님, 아래 근거 참조):
로컬에서 수정된 `public/favicon.png`를 원격 커밋이 **삭제**하기 때문에 git이 덮어쓰기를 거부한다.

## 현재 상태
- 로컬 main: origin/main 보다 **15 커밋 뒤짐**, 앞선 커밋은 **0개** (내가 안 올린 커밋 없음)
- 워킹트리 변경:
  - `M  public/favicon.png` — HEAD 버전(`0911aaa`)과 다른 내용(`65c62e9`, 6,740 bytes, 09-08 15:40 수정)
  - `?? src/assets/images/iMac-and-iPhone-Pro-Showcase-Screens-Free-psd-Mockup.png` — 추적 안 됨

## 충돌 근거
- `origin/main`에는 `public/favicon.png`가 **없다** (삭제됨).
- 대신 `public/favicon-bon.png` (14,129 bytes)가 추가됐고, `index.html` 6번 줄이
  `/favicon.png` → `/favicon-bon.png` 로 바뀌었다.
- 즉 원격은 파비콘을 새 파일로 교체한 상태이고, 로컬은 옛 파일을 따로 수정해 둔 상태다.

## 영향 범위 (데이터 손실 여부)
- **손실 위험 있는 것: `public/favicon.png`의 로컬 수정본 1개.** 커밋된 적 없어 git 어디에도 백업이 없다.
- 추적 안 되는 목업 PNG는 원격에 같은 파일이 없어 **영향 없음** (pull 해도 그대로 남는다).
- 그 외 15개 커밋(히어로/GNB/프로젝트 스크롤 연출/경력 여백 등)은 로컬에 겹치는 수정이 없어 그냥 들어온다.

## 추정 원인 (확정 아님)
다른 창/세션에서 파비콘을 `favicon-bon.png`로 교체·커밋해 푸시했고, 이 폴더에서는 그 전에
기존 `favicon.png`를 따로 손봐 둔 채 남아 있는 것으로 보인다. 로컬 수정본이 새 파비콘과
같은 이미지인지 다른 이미지인지는 **확인 안 됨** (내용 비교는 사용자 확인 필요).

## 선택지별 조치안

**A. 로컬 favicon.png 수정본 버리고 pull** (원격 파비콘 채택 — 가장 단순)
```
git checkout -- public/favicon.png
git pull --ff-only origin main
```
→ 로컬 수정본은 영구 삭제된다. 원격의 `favicon-bon.png`가 실제 파비콘이 된다.

**B. 로컬 수정본을 백업해 두고 pull** (되돌릴 여지 남김 — 권장)
```
cp public/favicon.png _draft/img/favicon-local-backup.png
git checkout -- public/favicon.png
git pull --ff-only origin main
```
→ pull 후 백업본을 보고, 이게 더 낫다면 그때 `favicon-bon.png`를 교체하면 된다.

**C. 로컬 수정본을 stash로 보관하고 pull**
```
git stash push -m "local favicon" public/favicon.png
git pull --ff-only origin main
git stash list   # 필요할 때 pop
```
→ 원격이 파일을 삭제했으므로 나중에 `stash pop` 시 충돌이 날 수 있다. B보다 번거롭다.

## 사용자에게 확인할 것
1. `public/favicon.png`의 로컬 수정본, 살릴 가치가 있나? (다른 창에서 만든 `favicon-bon.png`가 최종안인지)
2. A / B / C 중 무엇으로 진행할까? (기본 추천: **B**)
