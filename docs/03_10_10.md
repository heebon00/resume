## 3. 발견 사항 (조치 안 함 — 승인 대기)

### A. 스크롤 연출 설명글이 이미지에 가려짐 · 1440 / 1920 양쪽

`ProjectsReveal` 구간에서 `주요기술: … Tailwind CSS,등` 의 **끝부분이 오른쪽 목업 이미지 아래로 들어간다.**
1920에서는 마지막 글자 `등` 만, 1440에서는 `Tailwind CSS,등` 구간이 잘린다.

- 해당 문구: `src/content/portfolio.js:146` (iKEA), `src/content/portfolio.js:164` (YouTube Music)
- 렌더 위치: `src/sections/ProjectsReveal.jsx:233`
- git log 상 `1ef2251`, `13a90aa`에서 이미지를 오른쪽으로 미는 방식(margin-left 60→90)으로 이미 두 차례 대응했으나 **완전히 해소되지 않았다.**

추정 원인(**확정 아님**): 이미지를 밀어내는 방식이라 설명글 길이가 늘면 다시 겹친다. 텍스트 폭 상한이나 컬럼 분리가 없어 보인다.

선택지
1. 설명글 컨테이너에 `max-width`를 주어 이미지 좌변 앞에서 줄바꿈되게 한다 — 레이아웃 영향 최소
2. 텍스트 레이어의 `z-index`를 이미지 위로 올린다 — 어두운 목업 위에 검은 글씨라 가독성 나빠질 수 있음
3. 이미지를 더 오른쪽으로 민다 — 지금까지 방식, 재발 가능
4. 문구에서 `,등` 을 뺀다 — 가장 간단하나 콘텐츠 변경

→ **1번을 권장한다.** 다만 시안 대비 줄바꿈 위치가 달라지므로 확인이 필요하다.

- `ABOUT.rows` — name·Birth·Contact·Certificate·Education **5행 전부 값이 `"이희본"`** (`portfolio.js:75-80`)

→ 실제 생년월일·연락처·자격증·학력, 실제 경력 4건을 주시면 반영하겠다.
