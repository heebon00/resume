# 폰트 자체 호스팅 전환 + meta description 추가 (2026-09-03 11:11)

승인 내용: 설명문 **A안** 채택, 폰트는 **자체 호스팅** 방식으로 진행.
대상: `docs/web-check-2026-09-03.md` 7장의 남은 항목 2·3번.

---

## 1. 무엇을 했나

### A. `<meta name="description">` 추가

`index.html` `<head>` 에 A안 문구를 넣었다.

> 좋아하는 일에는 애정을, 맡은 임무에는 책임감을. 웹 퍼블리싱·인터랙티브 웹을 만드는 이희본의 포트폴리오입니다.

### B. 폰트 8종을 전부 자체 호스팅으로 전환

전에는 `<head>` 에서 외부 CSS 4개(jsdelivr 2개 + Google Fonts 2개)를 불러왔고,
그 4개가 **전부 렌더링을 막았다**(FCP 5.1초의 주범으로 지목된 항목).

지금은 폰트 파일을 `public/fonts/` 에 직접 두고, `src/styles/fonts.css` 의
`@font-face` 가 같은 도메인에서 바로 가리킨다. 이 CSS 는 번들에 합쳐지므로
**추가 요청이 생기지 않는다.**

| 서체 | 받은 것 | 크기 |
|---|---|---|
| Pretendard Variable | 동적 서브셋 92개 (배포본과 동일 구성) | 3.1 MB |
| Paperlogy | 800 ExtraBold 1개 | 155 KB |
| Big Shoulders Display / Stencil Display / Geist / Inter / Pinyon Script / VT323 | latin · latin-ext 서브셋 12개 | 436 KB |

**저장소에는 3.7 MB 가 늘었지만, 브라우저가 실제로 받는 양은 그보다 훨씬 적다.**
Pretendard 는 화면에 쓰인 글자가 속한 서브셋만 받는다 — 이번 측정에서 92개 중 **10개만** 받았다.

## 3. 검증 결과

빌드 후 `dist` 를 띄우고 헤드리스 Chrome(CDP)으로 1920×1080 에서 위·중간·아래까지 스크롤하며 측정했다.

| 항목 | 결과 |
|---|---|
| 외부 폰트 도메인 요청 (jsdelivr / googleapis / gstatic) | **0건** |
| woff2 응답 15건 | **전부 200**, 전부 같은 도메인(`/fonts/…`) |
| 네트워크 실패 | 0건 |
| 콘솔 에러 · 예외 | 0건 |
| 실제 적용된 서체 | Pretendard Variable 45–920 · Paperlogy 800 · Big Shoulders Display 100–900 · Big Shoulders Stencil Display 100–900 · Inter 100–900 · VT323 400 |
| 히어로 화면 | 전과 동일 (Paperlogy 한글 카피 · 스텐실 200%/300% · CREATIVE/PORTFOLIO 라벨 정상) |
| 하단 화면 | 전과 동일 (스킬 카드 · 푸터 정상) |
| oxlint | exit 0 |
| 빌드 | 성공 (`index-*.css` 93.35 kB → gzip 23.96 kB) |

**글자가 기본 글꼴로 튀어 보이는 구간(FOUT)은 관찰되지 않았다.**
`font-display: swap` 은 그대로 두었고, 첫 화면 한글 카피용 Paperlogy 는 `preload` 로 미리 받게 했다.

## 4. 확인 안 된 것 — 성능 점수

**이번 측정은 로컬 서버(localhost) 기준이라 실제 성능 개선 폭을 말할 수 없다.**
외부 CDN 3곳에 순차 접속하던 지연이 이번 변경의 핵심인데, 로컬에는 그 지연 자체가 없다.
FCP 5.1초 / LCP 6.2초 / 성능 65점이 몇 점이 되는지는 **배포 후 다시 재야 안다.**
미리 단정하지 않는다.

---

## 5. 확인이 필요한 것

1. **배포해도 되는가?** 커밋·푸시는 아직 하지 않았다. 승인하면 커밋하고, 배포 뒤 성능을 다시 재서 보고하겠다.
2. `Geist` 와 `Pinyon Script` 는 토큰(`--font-geist`, `--font-script`)만 정의돼 있고 **화면에서 쓰이는 곳이 없다.**
   자체 호스팅에서는 안 쓰는 서체를 브라우저가 받지 않으므로 그냥 두어도 손해가 없어 **일단 그대로 두었다.**
   시안대로 쓸 자리가 있었던 것인지 확인이 필요하다.
3. Paperlogy 는 ExtraBold(800) 한 굵기만 받았다. 다른 굵기를 쓸 계획이 있으면 알려달라.
