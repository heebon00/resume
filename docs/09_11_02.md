## 문제
`src/components/MobileHeader.jsx:21` 이 **삭제된 `/favicon.png` 를 그대로 참조**한다.

```jsx
<img src="/favicon.png" alt="이희본 포트폴리오" width="36" height="36" ... />
```

- 새벽 커밋 `0e0eab7` (GNB 브랜드 로고 작업) 에서 `public/favicon.png` 를 지우고
  `public/favicon-bon.png` 를 넣으면서 `index.html` 은 고쳤는데, `MobileHeader.jsx` 는 안 고쳤다.
- `MobileHeader.jsx` 의 마지막 커밋은 09-04 (`108b4e4`), 이번 새벽 변경 대상에 안 들어갔다.
- 확인: `curl /favicon.png` → 200 이지만 `content-type: text/html`, 2,198 bytes.
  즉 파일이 없어서 Vite 의 SPA 폴백 index.html 이 돌아온 것. 실제 이미지는 없다.

## 영향 범위
- **1280px 미만(모바일/태블릿) 화면 좌상단 로고가 깨진 이미지로 뜬다.** `App.jsx:85` 에서 항상 렌더된다.
- 데스크톱(1280 이상)은 `DesktopNav` 를 쓰므로 영향 없음.
- 데이터 손실 없음. 표시 버그 하나.
- 프로덕션 빌드에서도 동일하다 (`public/` 참조는 그대로 통과되고 런타임에 404).

다른 창에서 진행된 작업이라 **확정은 안 됨.**
