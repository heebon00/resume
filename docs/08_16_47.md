## 3. 중요 — 이 네 이미지는 화면에 안 쓰인다

import 는 되지만 `IMAGES` 객체에 담기기만 하고 **어디서도 꺼내 쓰지 않는다.**

- `IMAGES.` 로 실제 참조되는 것은 `aboutPortrait` · `portrait` 둘뿐이다
  (AboutMe / Hero / MobileAbout / MobileHero)
- MY DESIGN 카드는 이 네 장이 아니라 임시 목업 SVG(`designMock01~04`)를 쓴다
  (`portfolio.js:250~255`)

즉 **import 4줄과 IMAGES 항목 4개를 지워도 화면은 하나도 안 바뀐다.**

## 4. 추정 원인 — 확인 안 됨

다른 창에서 MY DESIGN 이미지를 새로 넣으려고 기존 파일을 지운 것으로 보이나,
**확인 안 됨**이다. 지운 주체와 의도는 사용자만 안다.

## 5. 선택지 (조치 전 승인 필요)

- **A. import 4줄과 IMAGES 항목 4개를 지운다** (권장)
  화면 변화 0, 빌드 즉시 복구. 새 이미지를 나중에 넣을 때 그때 다시 추가하면 된다.
- **B. 삭제된 파일을 되돌린다** — `git checkout -- src/assets/images/design-*.webp`
  파일이 되살아나고 빌드도 복구된다. 지운 게 실수였다면 이쪽이다.
- **C. 새 이미지를 같은 이름으로 넣어 주신다**
  그때까지 빌드·배포는 멈춘다.
